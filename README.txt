URBANSTEP FOOTWEAR — VS CODE PROJECT

Files:
- index.html
- style.css
- script.js

HOW TO RUN:
1. Download and extract UrbanStep_Footwear_VSCode.zip.
2. Open the extracted folder in VS Code.
3. Make sure these 3 files are in the SAME folder:
   index.html
   style.css
   script.js
4. Install the VS Code extension "Live Server" by Ritwick Dey (recommended).
5. Right-click index.html.
6. Select "Open with Live Server".
7. The website will open in your browser.

WITHOUT LIVE SERVER:
You can also double-click index.html and open it directly in Chrome/Edge.
However, Live Server is recommended for development.
