# 👟 UrbanStep Footwear

> **Walk Your Style**

UrbanStep Footwear is a modern e-commerce website project designed for a fictional Indian footwear brand. The website focuses on a clean, responsive and user-friendly shopping experience for men's and women's footwear.

## 🌐 Live Demo

👉 [Visit UrbanStep Footwear](https://rishabsingh01.github.io/urbanstep-footwear/)

## ✨ Features

- 🏠 Modern homepage with hero section
- 👟 10-product footwear catalogue
- 🔍 Product search
- 🏷️ Category filtering
- 📦 Product detail view
- 📏 Shoe size selection
- 🛒 Add to Cart functionality
- 💳 Demo checkout experience
- 📱 Fully responsive design
- 🎨 Modern and clean UI
- ⚡ Interactive JavaScript features

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git & GitHub
- GitHub Pages
